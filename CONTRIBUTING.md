# Как внести вклад

Спасибо, что хотите улучшить Bioformats Analyzer Lavander!

## Сообщение об ошибке

Для **сообщения об ошибках/багах**:
1. Создайте issue в отдельной вкладке репозитория.
2. В заголовке напишите название ошибки или её краткую суть:
3. В описании напишите:
   - Версию Python
   - ОС, на которой запускалась программа
   - Шаги для воспроизведения ошибки
   - Ожидаемое и фактическое поведение программы

## Внесение изменений в проект

Для **внесения изменений**:
1. Создайте fork репозитория.
2. Создайте ветку для изменений:

    `git checkout -b "my_feature"`
    
3. Внесите изменения в файлы и закоммитьте их:

    `git commit -am "Added new feature"`
    
4. Запушьте изменения в Вашу ветку:

    `git push origin my_features`
    
5. Создайте pull-request для вынесения изменений на рассмотрение о включении в основную ветку.

> Все изменения в коде должны включать docstrings и проходить локальную сборку документации (sphinx).
